# アクション

動きは変化を説明します。それは決して飾らない。ほとんどのインターフェイスは全くアニメーション化しません。

<a id="tokens"></a>

## デザイントークン

| デザイントークン  | バリュー                         | 利用条件                                                     |
| ----------------- | -------------------------------- | ------------------------------------------------------------ |
| `duration-fast`   | 120ミリ秒                        | ホバー、プレス、フォーカスのカラー変更、トグル、各出口       |
| `duration-base`   | 200のms                          | ダイアログ、シート、コマンドパレットとトーストが入る         |
| `duration-slow`   | 320ミリ秒                        | 進展充填、スキャンメーター、ヒーロー、マーケティングの入り口 |
| `ease-standard`   | `cubic-bezier(0.2, 0.8, 0.2, 1)` | 状態の変更と小さな動きのデフォルト                           |
| `ease-emphasized` | `cubic-bezier(0.3, 0, 0, 1)`     | 到着するオーバーレイ                                         |
| `ease-exit`       | `cubic-bezier(0.4, 0, 1, 1)`     | どんなことでも、常に `duration-fast`                         |

<a id="what-moves"></a>

## 何が動くか

- **状態の変更** 色のフェード `duration-fast` (`transition-colors duration-fast ease-standard` 全てについて
  インタラクティブな制御)。
- **オーバーレイ** 200 ms で、強調された曲線で入力し、出口曲線で 120 ms で残します。中央のダイアログ
  0.96からフェードとスケール、エッジからシートスライド、コマンドパレットはトップから8 pxをドロップし、トーストが上昇します
  8 px. そのパネルでスクリムがフェード. メニューとツールチップはアニメーションなしで表示されます.
- **プログレッシブ** 値をアニメーション化し、後方をジャンプし、最初の現実までのみ、インデモレネート状態を表示しません。
  番号は到着します。
- **マーケティングページ** 遅い包囲された動き(呼吸の白熱、漂流の土のリング、浮遊アイコン)を使用するかもしれません
  compositor (transform, opacity) のみ。

<a id="what-never-moves"></a>

## 決して動くこと

- レイアウト。 ユーザーが読み込んだり、タイプを読んだりすると、コンテンツがスライドしたり、非表示にしたり、リフローしたりしません。 参照
  [原則 › ポインターの下に安定](principles.md#4-stable-under-the-pointer).
- テーマスイッチ:色は単一のフレームで変わります()`applyThemePreference` そのフレームのトランジションを無効にします。
- 固定なし(モニター、カウンター)の変更で更新する番号。

<a id="reduced-motion"></a>

## 減らされた動き

`base.css` すべてのアニメーションをクランプし、0.01 ms に移行します。 `prefers-reduced-motion: reduce`滑らかに取除き、
スクロール。情報を伝えるためにアニメーションに依存しないでください。エンドの状態は、自分自身に感銘を与える必要があります。
