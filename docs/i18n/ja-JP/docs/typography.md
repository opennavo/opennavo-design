<a id="small-text"></a>

### 小さなテキスト

密なデスクトップUIは、常に色のトークンで、いくつかの内部サイズを使用しています。 12.5 pxは、コンパクトなコントロールとテーブルのために
11.5 px のセルは、行の下のメタデータ、小さなバッジの 10.5 px です。 10.5 px 以下は何も小さくありません。
12 px は必須情報を運びます。
