# Типография

<a id="typeface"></a>

## Типовой знак

Приложения используют **системный UI шрифт** — SF Pro на платформах Apple, Segoe UI на Windows — через
`@opennavo/design-vue/system-fonts.css`, с платформой CJK лица для китайцев и японцев:

| Язык                                                         | Stack (system-fonts.css)                                                          |
| ------------------------------------------------------------ | --------------------------------------------------------------------------------- |
| Латинский, кириллический                                     | `-apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif`                       |
| Упрощенный китайский`:lang(zh)`)                             | `-apple-system, BlinkMacSystemFont, 'PingFang SC', 'Microsoft YaHei', sans-serif` |
| Традиционный китайский ()`:lang(zh-Hant)`, `zh-TW`, `zh-HK`) | `… 'PingFang TC', 'Microsoft JhengHei', sans-serif`                               |
| Японцы.`:lang(ja)`)                                          | `… 'Hiragino Sans', 'Yu Gothic', sans-serif`                                      |
| Код, версии, пути                                            | `ui-monospace, 'SFMono-Regular', Menlo, Consolas, 'Liberation Mono', monospace`   |

Шрифт системы соответствует операционной системе, не стоит загрузки и делает CJK лучшим.
(`font.family.*`которые начинаются с Inter) являются **фирменный стек** для мест, где системный шрифт недоступен
или не нужен: генерируемые изображения для обмена, маркетинговые работы и галерея компонентов. `lang` на `<html>` (и далее)
любой элемент на другом языке), поэтому применяется правильный стек.

InterКогда используется, работает с `font-feature-settings: "cv11", "ss01"` (одноэтажные а, альтернативные цифры) и
`font-optical-sizing: auto`; `base.css` Устанавливает оба.

<a id="scale"></a>

## масштаб

`text-{name}` - устанавливает размер, высоту линии, вес и отслеживание вместе. Используйте шкалу; не устанавливайте размеры шрифта вручную
За исключением плотных размеров, перечисленных в Small text .

| Класс           | Размер/высота линии | вес | Отслеживание           | Использовать                                    |
| --------------- | ------------------- | --- | ---------------------- | ----------------------------------------------- |
| `text-hero`     | 76 / 78             | 600 | -0.035em               | Домашний герой / Home Heroes                    |
| `text-section`  | 46 / 50             | 600 | -0,03em                | Заголовки разделов сайта                        |
| `text-display`  | 40 / 44             | 600 | -0,03em                | Характерные заголовки героев                    |
| `text-title1`   | 28 / 34             | 600 | -0,02em                | Заголовки страниц                               |
| `text-title2`   | 22 / 28             | 600 | -0,02em                | Диалог заголовков, компактные заголовки деталей |
| `text-headline` | 16 / 24             | 600 | -0.01em                | Заголовки разделов, названия карт               |
| `text-stat`     | 20 / 26             | 600 | -0.015em               | Статистические ценности                         |
| `text-body`     | 14 / 22             | 400 | 0                      | Текст текста тела                               |
| `text-body-sm`  | 13 / 20             | 400 | 0                      | Списки, таблицы, строки настроек                |
| `text-caption`  | 12 / 18             | 400 | 0                      | Вторичная информация                            |
| `text-label`    | 11 / 16             | 600 | 0,08м, верхний регистр | Групповые этикетки (боковые секции, брови)      |
| `text-mono`     | 12 / 18             | 400 | 0                      | Команды, версии, журналы                        |

На узких экранах заголовки понижают шкалу, а не сжимаются свободно: домашний герой `text-display` ниже
768 px, `text-section` от 768 х и `text-hero` от 1024 px; заголовки персонажей падают до 36 px ниже 768 px.
Окна никогда не опускаются ниже минимальной ширины, поэтому текст приложения не масштабируется.

<a id="small-text"></a>

### Небольшой текст

Плотный пользовательский интерфейс рабочего стола использует несколько промежуточных размеров, всегда с токенами для цвета: 12,5 пикселей для компактных элементов управления и стола
ячейки, 11,5 px для метаданных под строкой, 10,5 px для крошечных значков. Ничего меньше 10,5 px и ничего ниже
12 px содержит важную информацию.

<a id="rules"></a>

## Правила

- **Номера:** использовать `tabular-nums` где цифры выстраиваются в линию или меняются (статистика, таблицы, прогресс,
  - счетчики, мониторы. Номера форматов, размеры и даты для местности ([Контент](content.md)).
- **Вес:** 400 для текста, 500 для элементов управления и сегментированных меток, 600 для заголовков, кнопочных меток и акцентов.
  700+ в интерфейсе.
- **Акцент:** жирный (600) в предложении, никогда не цвет в одиночку. `**…**` и
  быть представленным как `text-ink-primary` Вес 600 внутри вторичного текста.
- **верхний ящик** только через `text-label`, и только для латыни и кириллицы; ярлыки CJK не трансформируются.
- **Длина линии:** Сохраняйте текст тела под 72 символами (или 40 символами CJK) на строку; описания в героях
  Они ограничены около 430 px.
- **Заголовки** уравновешивать их линии;`text-wrap: balance`) на маркетинговых страницах; заголовки CJK разбиваются в пунктуации, а не
  среднее слово, где позволяет браузер.
- **Усечение:** усечение однострочных этикеток с эллипсисом и раскрытие полного текста в подсказке или `title`;
  Никогда не сокращайте числа и статус.
- **CJK интервал:** Копия ставит одно полуширотное пространство между CJK и латинскими буквами или цифрами («- 30 天», англ.)
  "载 768 МБ") и ни один рядом с полноразмерной пунктуацией. `text-autospace: normal` в `base.css` заполняет только пробел в
  Пропущенная копия никогда не заменяет пространство в исходном тексте.
