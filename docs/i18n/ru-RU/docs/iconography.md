# иконография

<a id="interface-icons"></a>

## Иконки интерфейса

- **Набор:** [Lucide](https://lucide.dev) (ISC лицензионные), в комплекте с автономным подмножеством — только значки, перечисленные в
  `packages/vue/src/icons/names.ts` судна, выполненного в виде встроенного SVG, чтобы они работали в SSR И без сети.
- **Размеры:** 16 px в меню и навигации, 15 px в меню `md`/`lg` Кнопки, 14 px in `xs`/`sm` Кнопки и чипы, 12-13 px
  в соответствии с метаданными. Иконки внутри 26-32 px рендер на 14-16 px.
- **Инсульт и цвет:** Lucide2 px ход при 24 px, масштабированный; иконки берут `currentColor`Поэтому они следуют тексту
  Не окрашивайте иконки независимо, если они не имеют статуса.
- **Значение:** одна иконка для каждой концепции в приложении (например, `circle-arrow-down` для обновлений, `shield-check` для
  охрана, `eraser` Для уборки. Кнопки только для иконок всегда имеют `aria-label` и подсказку.
- **Добавление иконок:** Пакет объединяет только значки, которые рисуют его компоненты. Приложение добавляет свои собственные
  `registerIcons(getIcons(lucide, ['compass', 'settings']))` (`@iconify/utils` + `@iconify-json/lucide`или любой установленной в
  иконизировать JSON форма, рассматриваемая как `prefix:name`) один раз при запуске, так что его пакет несет только то, что он использует.
  Компоненты сами по себе должны быть `packages/vue/src/icons/names.ts`Тогда `pnpm gen`Неизвестные имена дают
  Ничего и предупреждать в развитии.
