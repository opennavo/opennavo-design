# Бренд

OpenNavo Дизайн делится на семейство приложений. Они разделяют все, кроме тонкого слоя бренда, так что человек, который знает
Одно приложение уже знает другие.

<a id="the-brand-layer"></a>

## Брендовый слой

Приложение может изменять только эти токены (с обоими значениями темы):

| Дизайн-токен                                                                         | Что несет в себе                                                                                      |
| ------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------- |
| `brand.coral`                                                                        | Заполнение акцента: кнопки акцента, переключатели, прогресс, цвет кольца фокусировки, маленькие точки |
| `text.accent`                                                                        | Акцентный текст и ссылки                                                                              |
| `accent.coralSubtle`                                                                 | Accent оттенки за чипами и треки прогресса                                                            |
| `button.accentBg`, `button.accentHover`, `button.accentPressed`, `button.accentText` | Кнопка акцента                                                                                        |
| `shadow.focusRing`                                                                   | Кольцо фокусировки (сохраняйте зазор 2 px + форму кольца 2 px)                                        |
| `component.runningBorder`                                                            | Граница выполняемой задачи                                                                            |
| `brand.salmon`, `accent.salmonSubtle`                                                | Теплый акцентный текст и значки                                                                       |
| `brand.violet`, `effect.heroGlow`, `effect.coverGlow`                                | Герой светится                                                                                        |
| `brand.logoGradient`, `brand.logoCoreGradient`                                       | Собственная отметка приложения                                                                        |

Имена токенов остаются прежними.`brand.coral` сохраняет свое название, даже если акцент приложения синий, поэтому компоненты и документы
никогда не вилки. Создайте токены приложения с помощью файла override ([Theming › Ребрендинг](theming.md#re-branding-another-app))
И держите контрастные тесты зелеными: акцентный текст должен по-прежнему достигать 4,5:1 в обеих темах, а акцент заполнять 3:1.

Все остальное — нейтральные цвета, цвета статуса, тип, расстояние, радиусы, движение, компоненты и узоры — это то же самое.
Каждое приложение.

<a id="names-and-marks"></a>

## Имена и знаки

- Каждое приложение имеет свое имя и отметку. Компоненты проносят отметку через `brand` слот; система проектирования не поставляется
  логотип.
- The OpenNavo Название и логотип являются товарными знаками OpenNavo Авторы и являются **не** Охраняемый этим репозиторием MIT
  лицензия[TRADEMARKS.md](../TRADEMARKS.md)Приложения, построенные на системе, не должны использовать их в качестве собственного имени или значка.
- Префикс компонента `On` и тот CSS префикс `--on-` Они принадлежат системе, а не продукту, их нужно сохранить.

<a id="using-the-mark-well-for-opennavo-itself"></a>

## Использование знака хорошо (для OpenNavo сама по себе

- Словосочетание находится рядом с отметкой в 15 px, вес 600, в `brand.coral`; отметка 22 px высотой рядом с ним.
- Ниже 32 пикселей отметка использует свою упрощенную геометрию. Сохраняйте чистое пространство, по крайней мере, в половине высоты отметки.
- На светлом фоне звезда в знаке переключается на градиент ядра янтаря; никогда не помещайте знак на занятое изображение.
