# Движение

Движение объясняет изменение; оно никогда не украшает. Большая часть интерфейса вообще не оживляет.

<a id="tokens"></a>

## Дизайн-токены

| Дизайн-токен      | ценность                         | Использовать                                                                 |
| ----------------- | -------------------------------- | ---------------------------------------------------------------------------- |
| `duration-fast`   | 120 мс                           | Цвет меняется на висение, нажатие и фокусировка; переключатели; каждый выход |
| `duration-base`   | 200 мс                           | Диалоги, листы, командная палитра и тосты, входящие                          |
| `duration-slow`   | 320 мс                           | Прогресс заполнения, скан-метры, герои и маркетинговые входы                 |
| `ease-standard`   | `cubic-bezier(0.2, 0.8, 0.2, 1)` | Дефолт для изменений состояния и небольших движений                          |
| `ease-emphasized` | `cubic-bezier(0.3, 0, 0, 1)`     | Оверлеи прибывают                                                            |
| `ease-exit`       | `cubic-bezier(0.4, 0, 1, 1)`     | Все, что уходит, всегда с `duration-fast`                                    |

<a id="what-moves"></a>

## Что движется

- **Государственные изменения** Цвета с блеском `duration-fast` (`transition-colors duration-fast ease-standard` на всех
  интерактивный контроль.
- **Наложения** войти в 200 мс с выделенной кривой и выйти в 120 мс с кривой выхода: центрированные диалоги
  выцветают и масштабируются от 0,96, листы скользят с края, командная палитра падает на 8 пх сверху, поднимаются тосты
  8 px. Скрам исчезает с панелью. Меню и подсказки появляются без анимации.
- **Прогресс** Оживляет свою ценность, никогда не прыгает назад и показывает неопределенное состояние только до первого реального состояния.
  Номер прибывает.
- **Маркетинговые страницы** может использовать медленное движение окружающей среды (дыхательное свечение, дрейфующие пунктирные кольца, плавающие значки) на
  Композитор (трансформация, непрозрачность).

<a id="what-never-moves"></a>

## Что никогда не движется

- Контент не скользит, не разрушается и не перетекает, пока пользователь читает или типирует; см.
  [Принципы › Стабильность под указателем](principles.md#4-stable-under-the-pointer).
- Тематические переключатели: цвета меняются в одном кадре`applyThemePreference` Отключает переходы для этого кадра.
- Номера, которые обновляются на месте (мониторы, счетчики), меняются без подкачки.

<a id="reduced-motion"></a>

## Уменьшенное движение

`base.css` зажимает каждую анимацию и переходит на 0,01 мс под `prefers-reduced-motion: reduce`и удаляет гладкие
Не полагайтесь на анимацию для передачи информации; конечное состояние должно иметь смысл само по себе.
