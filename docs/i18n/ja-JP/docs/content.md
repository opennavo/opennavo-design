# コンテンツ

単語はインターフェイスです。同じルールはすべての言語で適用します。英語と簡体字は最初に書かれています、
他の8つの言語は、それらから翻訳され、レビューされます。

<a id="voice"></a>

## ボイス

平らで、具体的で落ち着きのある — 何が起こっているのか、営業マンではなく、ログファイルではないことを説明できる友達。

- **何が起こるかを言いなさい。** 「ゴミ箱に14個のアイテムを置きます。そこからそれらを復元できます。」ではなく、「確かに?」
- **データがどこにあるかを言います。** 「このMacでしかアップロードされていない」 「このMacからAppleに直進する」
- **自分の失敗は、次のステップを提供します。** 「コンテンツが読み込まれない場合があります。過去にコンテンツが読み込まれています。」
  「更新チェックは完了できませんでした。もう一度お試しください。ネットワークをチェックしてください。」
- **ハイプ、フィラーなし。** 「おっと!」、除外マークなし、無 "simply"、"just"、"seamlessly"、"powerful"はありません。
- **抽象的な上のコンクリート。** アプリ名、カウント、サイズ、時間。 "Docker Desktop は管理者が必要
  許可」が「許可が必要」を打ちます。

<a id="wording-rules"></a>

## 言葉のルール

- **ボタン** アクションの名前は動詞です: インストール、すべての更新(4)、ゴミ箱に移動、ロールバック、オープン OpenNavo.
  英語ボタンのラベルとメニュー項目は、タイトルケースを使用します。 それ以外のものは、文の場合を使用します。
- **タイトル** "あなたのリストは空です"、 "vscode"の検索結果はありません。
- **コンテンツ** ひとつの文です。ほとんど2つ。説明の後にアクションを置きます。
- **ヒント** 設定下では、ラベルが既に言うものではなく、オプションがオンになっていると言います。
- **確認ダイアログ**: タイトルは、特定の質問を尋ねます((このMacから「作業」を削除しますか?)、ボディは、
  その結果、ボタンが動詞を繰り返すことを確認します。
- **エラー**: ユーザの用語で、間違ったこと、そして何をすべきか。 エラーコードは、タイトルではなく、詳細やログに行きます。
- **プライバシーライン** ロックアイコンからスタートし、1つの行を続けます。
- カルリー引用符(「 」)、実際のアポストトロフィー、エリプシス文字(...)、乗算記号(×)、
  バージョン変更のための矢印(→): `1.2.9 → 1.3.0`.
- 製品およびプラットフォーム名は、その綴りを保ちます。 macOS, iPhone, アプリストア, GitHub, Homebrew. アプリ名は、
  開発者はそれらを書きます。

- 按钮用动词短语：“安装”“全部更新（4）”“移到废纸篓”。不要“确定”“好的”。
- 在 “ “ “ “ “ “ “ “ “ 近 近 近 近 近 近 近 近 近 近 近 近 近 近 近 近 近 近 近 “ 近 近 “ “ 近 近 “ “ “ “ “ “ “ “ “ “ “ “ “ “ “ “ “ “ “ “ “ “ “ “ OpenNavo 中打开”；与全角标点相邻时不加。
- 全角标点：，。；：？！“”（）——……；引号用“”，嵌套用‘’。
- 数量用“个”“款”“项”等合适的量词，大数用“万”“亿”（由格式化函数处理）。

ルール:

- **最長の言語の設計。** サイドバーのラベルは13.5 pxで152 pxを占めています。ロシア、スペイン語、スペイン語、そして
