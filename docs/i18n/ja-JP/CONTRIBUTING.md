<a id="ground-rules"></a>

## グラウンドルール

- **最初にトークン。** 変更点 `tokens/tokens.json`, 実行 `pnpm gen`, 生成されたファイルを変更でコミットします。 決して
  generated というファイルを編集します。
- **テーマは両方。** 新しいカラートークンは、暗くなっています。 `value` そして、それが異なるとき、a `light` 値。追加または更新
  任意の新しいテキスト/背景のペアのコントラストテスト ()`packages/tokens/tests`).
- **役割は、見ない。** 既存のトークンが正しい色を持っているが、間違ったジョブの場合は、ジョブのトークンを追加します。
  ([docs/principles.mdの](docs/principles.md#rules-that-settle-arguments)).
- **コンポーネントは汎用性を維持します。** 商品名、製品データ形状、ネットワークコールなし `packages/vue`; アプリパス
  プロップとスロットを通してコンテンツ。
- **Docs はコードで移動します。** 新しいトークン、コンポーネントのプロップ、または動作はマッチングページを更新します。 `docs/`.
- **まずは英語を。** ドキュメント、ソースコメント、エラー、開発者がデフォルトを英語にツールします。英語(英語)`en-US`) はコンポーネント文字列のソース言語です。明示的にローカライズされたコンテンツを保存します。
- **10言語** 新しいコンポーネントの文字列は、すべての 10 個のメッセージファイルに移動します `packages/vue/src/messages`, マッチングキーとプレースホルダー付き. 英語はデフォルトのままです; ブラウザの設定から言語を侵入しません.

<a id="security-review-before-commits"></a>

## コミット前のセキュリティレビュー

実行する `pnpm secrets:worktree` 変更の準備中、意図したファイルを段階的にし、実行します `pnpm secrets:staged`.
実行する `pnpm secrets:history` 到達可能な履歴を発行する前に。これらのコマンドはGo 1.23+とネットワークアクセスが必要です。
ピン留めの最初のダウンロードのために Gitleaks スキャナ。スキャナの故障は、チェックをブロックします。それをバイパスしないでください。

ステージされたファイルと、既存の変更、生成されたファイル、アセットを含む、完全なステージド・ディフュージョンをすべて見直します。
認証情報、秘密鍵、環境設定、プライベートサービスアドレス、または個人データをコミットしないでください。
プレースホルダとフィクスチャーを使用してください。 ファイルを無視しても、追跡または段階的には保護しません。
バイナリの添付ファイルが公開できることを確認します。スキャン結果はパス、行番号、ルールIDのみを表示します。
クリーンなスキャンは、手動レビューを置き換えません。 任意の段階的なコンテンツの変更後に再確認します。

個別に利用するレポート脆弱性 [SECURITY.mdの特長](SECURITY.md). 公共の問題やログに秘密が含まれていません。

英語の慣習的なコミットメッセージと英語を使う GitHub タイトルとメモを解放します。変更されたものを記述して下さい、
なぜ、実際に実行されているかをチェックします。リモートCIを渡すようにローカルテストを記述しないでください。 API 安定性はではないです
1.0 以前は、変更履歴の変更を破棄する文書が約束されます。

<a id="translations-and-previews"></a>

## 翻訳とプレビュー

英語は、すべての10言語のソースです。 `en-US`, `zh-CN`, `zh-Hant`, `ja-JP`, `es-ES`, `pt-BR`, `ru-RU`,
`de-DE`, `fr-FR` そして、 `it-IT`. コンポーネントメッセージは、 `packages/vue/src/messages`;ギャラリーメッセージは、
`packages/vue/gallery/src/messages`. 可視された物語のコピー、および運行およびアクセス可能なラベルを翻訳して下さい。
コンポーネント名、enum 値、URL、コードサンプル、ライセンス元の変更は行いません。

完全なドキュメントミラーは、 `docs/i18n/<locale>/`、英語リポジトリのパスに従って。
新しい翻訳は、オフラインの機械支援草案として始まり、言語レビュー、特に技術的で法的です
prose. 英語は権威を維持します。. 一般的なポルトガル語とは別にブラジルポルトガル語の語彙を見直します。.
英語が変更されると、対応するファイルをすべての言語で更新し、SHA-256を
`docs/i18n/manifest.json`. 実行 `pnpm check:i18n` 適用範囲、源の新鮮さ、リンクおよびコード例を確かめるため。
マニフェストは、翻訳を更新せずに失敗を消すだけに更新しないでください。

READMEスクリーンショット `docs/previews` フィクションサンプルデータを実際のギャラリーから表示します。 それらをキャプチャ
ブラウザのクロームや個人情報なしで、文書化されたテーマと言語でブラウザの使用。
