# ブランド

OpenNavo デザインは、アプリの家族によって共有されます。彼らは、薄いブランド層を除いて、すべてのものを共有するので、知っている人
1つのアプリは既に他人を知っています。

<a id="the-brand-layer"></a>

## ブランドレイヤー

アプリは、これらのトークンのみを変更することができます(両方のテーマ値で)。

| デザイントークン                                                                     | それが運ぶもの                                                              |
| ------------------------------------------------------------------------------------ | --------------------------------------------------------------------------- |
| `brand.coral`                                                                        | アクセントの盛り土: アクセント ボタン、トグル、進行、焦点リング色、小さい点 |
| `text.accent`                                                                        | アクセントカラーのテキストとリンク                                          |
| `accent.coralSubtle`                                                                 | チップと進捗状況の追跡の背後にあるアクセントスズ                            |
| `button.accentBg`, `button.accentHover`, `button.accentPressed`, `button.accentText` | アクセントボタン                                                            |
| `shadow.focusRing`                                                                   | 焦点リング(2 px ギャップ + 2 px リング形状)                                 |
| `component.runningBorder`                                                            | 実行中のタスクの境界                                                        |
| `brand.salmon`, `accent.salmonSubtle`                                                | 温かみのあるテキストとバッジ                                                |
| `brand.violet`, `effect.heroGlow`, `effect.coverGlow`                                | 英雄の輝き                                                                  |
| `brand.logoGradient`, `brand.logoCoreGradient`                                       | アプリ独自のマーク                                                          |

トークン名は同じままです(`brand.coral` アプリのアクセントが青色である場合でも、その名前を保持します。
決してフォークしません。アプリのトークンをオーバーライドファイルで生成します()[Theming › 再ブランディング](theming.md#re-branding-another-app))
コントラストテストを緑に保つ:アクセントテキストは、両方のテーマで4.5:1に達し、アクセントは3:1を満たしている必要があります。

その他 — 中立、ステータス色、タイプ、間隔、半径、モーション、コンポーネント、パターン — は同じです。
すべてのアプリ。

<a id="using-the-mark-well-for-opennavo-itself"></a>

## マークをよく使う(for) OpenNavo それ自体)

- ワードマークは、15 px、600 のマークの横に座っています。 `brand.coral`;; マークは22pxの高さです。
- 32 px 以下では、マークは単純化されたジオメトリを使用します。マークの高さの半分以上をクリアなスペースにしてください。
- 光の背景では、マークの星がアンバーコアグラデーションに転換します。 決して忙しいイメージにマークを配置しません。
