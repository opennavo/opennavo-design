# Marcas

El MIT licencia de este repositorio cubre su código y documentación. No otorga ningún derecho a los nombres,
logos u otras marcas de los OpenNavo autores.

- "OpenNavo"y el OpenNavo logotipo (la N con la estrella) son marcas comerciales de la OpenNavo autores.
  no contiene ninguna obra de logotipo; los componentes aceptan la marca de cada aplicación a través de una `brand` ranura.
- Usted puede decir que una aplicación "usa OpenNavo Diseño" o "se construye con OpenNavo Diseño", siempre y cuando la declaración sea
  precisa y no sugiere que el OpenNavo autores hicieron, respaldaron o apoyaron esa aplicación.
- No use el OpenNavo nombre o logotipo, o confusivamente similares, como el nombre, icono o marca de otro producto.
- El prefijo del componente `On` y el CSS prefijo variable `--on-` son parte del sistema de diseño API y se puede utilizar
  libremente.

Nombres de terceros mencionados en la documentación (macOS, App Store, GitHub, Homebrew y otros) pertenecen a su
dueños.
