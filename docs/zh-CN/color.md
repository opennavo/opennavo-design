# 颜色

> 英文原文：[color.md](../color.md)。两者不一致时以英文版为准。

所有颜色都来自令牌。每个颜色令牌都有一个深色值（默认值），与深色不同时还有一个浅色值；[令牌参考](../reference/tokens.md)列出了全部令牌。本页说明各个令牌的角色——选对令牌，靠的就是了解角色。主题的实现机制见[主题](theming.md)。

## 两套主题的区别

- **深色**主题按亮度逐级抬高表面：page `#0B0B0B` → base `#131313` → card `#1A1A1A` → raised `#262626`。层级越高，看起来越亮。
- **浅色**主题保持同样的顺序，但不可能比白色更白：page `#F2F2F2` → base `#F8F8F8` → card `#FFFFFF`。高层级的面板是白色，加边框和柔和的阴影；白色卡片里的填充（`cardAlt`、`raised`、`chip`）是灰色，所以看起来是凹进去的。
- 边框在深色模式下是半透明白色，在浅色模式下是半透明黑色，强度相近。
- 品牌色和状态色在浅色模式下更深，以保证文字在白底上仍有 4.5:1 的对比度。

不得照着某一套主题的截图凭肉眼取色。要选角色，令牌会同时带上两套取值。

## 表面

| 令牌              | 角色             | 用于                                                                            | 不用于                             |
| ----------------- | ---------------- | ------------------------------------------------------------------------------- | ---------------------------------- |
| `surface.page`    | 最外层背景       | 网站页面主体、顶部导航栏、浮动窗口背后的区域                                    | 应用外壳内的内容区                 |
| `surface.base`    | 主内容背景       | 应用外壳的内容栏、窗口背景                                                      | 卡片                               |
| `surface.sidebar` | 侧边栏           | 左侧导航栏                                                                      | 其他任何地方                       |
| `surface.rail`    | 右侧栏           | 宽窗口中可选的统计右侧栏                                                        | —                                  |
| `surface.card`    | 卡片和面板       | 卡片、列表容器、设置分组、菜单栏浮窗                                            | 浮在内容之上的面板（用 `popover`） |
| `surface.cardAlt` | 卡片内部         | 输入框、次级区块、表格行高亮、卡片内的提示框                                    | 页面级背景                         |
| `surface.raised`  | 悬停和小面积填充 | 悬停背景、分页中的当前页、图标底块、`⌘K` 提示                                   | 浮动面板；选中的分段               |
| `surface.chip`    | 中性徽标         | 中性标签（chip）、快捷键提示、小标签                                            | 按钮（用 `button.secondary*`）     |
| `surface.control` | 控件             | 设置中的文本输入框和下拉选择框、悬停提示                                        | 大面积区域                         |
| `surface.inset`   | 凹槽             | 代码块、日志、分段控件的轨道、进度条轨道                                        | 按钮                               |
| `surface.overlay` | 半透明浮层       | 菜单和命令面板，配合 20 px 的背景模糊                                           | 不透明面板                         |
| `surface.popover` | 浮动面板         | 隐私授权卡片和建议卡片、演示用浮窗——凡是带 `shadow.popover`、浮在内容之上的元素 | 页面流中的内容                     |

组件专用的表面放在 `component.*` 下：`modalBg` 用于对话框和侧边面板（sheet），`searchBg` 用于搜索框和页面中的表单输入框，`navActive` 用于选中的侧边栏项目，`segmentActive` 用于选中的分段，`heroBg` 用于功能主视觉；此外还有 `detailHeaderBg`、`toastBg`、`scrim`（对话框背后的遮罩）、`lightboxScrim`（图片查看器的遮罩，两套主题下都是深色，所以查看器整体用深色主题渲染，见[主题 › 局部主题](theming.md#局部主题)），以及 `menuBarBg` / `menuBarText`（应用内模拟的 macOS 菜单栏）。

## 文字

| 令牌             | 用途                                             | 深色           | 浅色           |
| ---------------- | ------------------------------------------------ | -------------- | -------------- |
| `text.primary`   | 标题、需要强调的正文、数字                       | 卡片上 14.9:1  | 卡片上 17.4:1  |
| `text.secondary` | 正文、描述                                       | 7.3:1          | 7.2:1          |
| `text.tertiary`  | 字段名、元信息、时间戳、提示                     | 5.4:1          | 5.3:1          |
| `text.disabled`  | 只用于禁用状态和纯装饰性的文字                   | —              | —              |
| `text.accent`    | 珊瑚色文字：链接、珊瑚色标签、需要强调的行内操作 | 6.5:1          | 5.7:1          |
| `text.inverse`   | 强填充色（状态色、珊瑚色、鲑鱼色）上的文字和图标 | 深色           | 白色           |
| `text.onAccent`  | 珊瑚色按钮和珊瑚色徽标上的文字                   | 珊瑚色上 7.2:1 | 珊瑚色上 5.5:1 |

规则：

- 一个组件里最多用三级文字。用户必须读到的内容，最低只能用 `text.tertiary` 这一级。
- `text.disabled` 绝不承载信息：禁用的控件必须在附近说明为什么不可用。
- **`brand.coral` 是填充色，不是文字颜色**。它在白底上只有 3.5:1。珊瑚色文字用 `text.accent`。
- 不得把 `text.tertiary` 放在 `surface.chip` 或 `surface.raised` 上排长文本，这些背景上改用 `text.secondary`。

## 边框

`border.subtle` 用于卡片边缘和分隔线，`border.default` 用于输入框、幽灵按钮和窗口，`border.strong` 用于悬停状态。`border.sidebar` 用来分隔侧边栏。状态面板使用对应的 `status.*Border`，配合同色系的 `status.*Subtle` 填充。

## 品牌色

| 令牌                                           | 用途                                                                             |
| ---------------------------------------------- | -------------------------------------------------------------------------------- |
| `brand.coral`                                  | 作为填充或图形使用的品牌强调色：强调按钮、进度、打开状态的开关、焦点环、小圆点。 |
| `brand.salmon`                                 | 暖色的强调文字：区块眉题、主视觉标题的第二行、“有可用更新”徽标。                 |
| `brand.violet`                                 | 主视觉光晕；营销页面上带色调的图标背景中也会混入这种颜色。                       |
| `brand.logoGradient`、`brand.logoCoreGradient` | 只用于 Logo 标志。在浅色背景上，核心渐变改为琥珀色。                             |

强调色的淡色版本：`accent.coralSubtle`（进度条轨道、珊瑚色标签）和 `accent.salmonSubtle`（鲑鱼色徽标）。叠在它们上面的文字分别用 `text.accent` 和 `brand.salmon`。

珊瑚色要克制地使用：每个视图只放一个强调按钮，并且绝不用珊瑚色表示错误（错误用 `status.danger`）。

## 状态色

| 色系      | 含义                                     | 典型用法                                     |
| --------- | ---------------------------------------- | -------------------------------------------- |
| `success` | 已完成、已安装、正常、已是最新           | “已安装”徽标、“一切正常”横幅、成功的日志行   |
| `warning` | 需要注意、需要管理员权限、只得到部分结果 | 已跳过的项目、管理员权限提示、“需要确认”标签 |
| `danger`  | 失败、已弃用、破坏性                     | 失败状态、危险按钮、发现的威胁               |
| `info`    | 中性信息、可自行更新的应用、文档中的链接 | 信息提示框、“自动更新”标签                   |

每个色系都有一个纯色（用于文字、图标、圆点）、`*Subtle`（10% 浓度的淡色背景）和 `*Border`（带色调的面板边框）。颜色要搭配图标或文字一起使用——状态绝不只靠颜色传达。

## 按钮

| 变体 | 令牌                                              | 用途                                                                 |
| ---- | ------------------------------------------------- | -------------------------------------------------------------------- |
| 主要 | `button.primary*`——深色下接近白色，浅色下接近黑色 | 视图的主操作。每个区域一个。                                         |
| 次要 | `button.secondary*`                               | 其他操作。默认变体。                                                 |
| 强调 | `button.accent*`（珊瑚色，深色文字）              | 体现品牌的时刻：主视觉区的行动按钮、“全部更新”。一屏里很少超过一个。 |
| 幽灵 | 透明，`border.default`                            | 工具栏和紧凑行中的第三级操作。                                       |
| 危险 | `status.dangerSubtle` + `status.danger`           | 破坏性操作。绝不作为对话框的默认按钮。                               |
| 禁用 | `button.disabled*`                                | 任意变体的不可用状态。                                               |

## 图表

`chart.series1`（紫色）、`chart.series2`（珊瑚色）、`chart.series3`（绿色）是分类色，选色时确保有常见色觉障碍的人也能区分；按这个顺序使用，系列超过两个时，直接在图上标注系列名称。单系列图表用 `chart.emphasis` 表示当前值，用 `chart.deemphasis` 表示历史值。`chart.grid` 和 `chart.axis` 都是细线。监控视图也可以用状态色和信息色表达含义（温度警告、网络下载/上传）。

## 对比度

按 WCAG 2.2 的公式计算；任何一组颜色低于目标值，`packages/tokens/tests` 都会让构建失败。

| 前景色                    | 目标值 | 深色（base / card / raised） | 浅色（base / card / raised） |
| ------------------------- | ------ | ---------------------------- | ---------------------------- |
| `text.primary`            | 4.5    | 15.9 / 14.9 / 12.9           | 16.4 / 17.4 / 14.9           |
| `text.secondary`          | 4.5    | 7.8 / 7.3 / 6.4              | 6.8 / 7.2 / 6.2              |
| `text.tertiary`           | 4.5    | 5.7 / 5.4 / 4.7              | 5.0 / 5.3 / 4.6              |
| `text.accent`             | 4.5    | 6.9 / 6.5 / 5.6              | 5.4 / 5.7 / 4.9              |
| `brand.salmon`            | 4.5    | 9.0 / 8.4 / 7.3              | 5.4 / 5.7 / 4.9              |
| `status.success`          | 4.5    | 9.2 / 8.6 / 7.5              | 5.3 / 5.6 / 4.8              |
| `status.warning`          | 4.5    | 10.1 / 9.5 / 8.2             | 5.3 / 5.6 / 4.8              |
| `status.danger`           | 4.5    | 6.1 / 5.7 / 5.0              | 5.4 / 5.7 / 4.9              |
| `status.info`             | 4.5    | 7.3 / 6.8 / 5.9              | 5.3 / 5.6 / 4.8              |
| `brand.coral`（用作图形） | 3.0    | 6.9 / 6.5 / 5.6              | 3.3 / 3.5 / 3.0              |

测试还覆盖了：状态色和强调色文字叠在各自淡色背景上的情况（淡色背景分别叠在 base、card 和 cardAlt 之上）、每种按钮状态、珊瑚色上的文字、终端图标，以及凹槽中的等宽文字。

## 该做与不该做

- 浮动卡片用 `bg-surface-popover shadow-popover border border-line-default`；不要复用 `surface.raised`——它在浅色模式下是灰色的。
- 营销页面的光晕需要某种色相时，用令牌混出半透明色调（`color-mix(in srgb, var(--on-status-success) 14%, transparent)`）；不要在组件里写十六进制或 rgba 值。
- 合并界面改动之前，两套主题都要检查；组件预览页和应用都只需改一个设置就能切换主题。
