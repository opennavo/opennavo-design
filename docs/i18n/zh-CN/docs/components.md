# 构成部分

每一组成部分的参考文献 [`@opennavo/design-vue`](../../../../packages/vue):它的目的是什么,它的道具,事件和
插槽(如来源中声明的),变体,何时使用,以及键盘和辅助技术的表现.
组件组合成屏幕的方式 [图案](patterns.md); 画廊(`pnpm gallery`) 显示
在两个主题和所有十种语言中都有变体。不使用的 Apps Vue 遵循同样的解剖学,大小和状态
直接用符号表示([平台](platforms.md)).

公约:

- **默认** `—` 表示道具是可选和未设置的;没有列出默认的布尔道具是 `false`.
- 内建字符串("Close","Pagination","Search"...)来源于该包在本地域的信息目录
  给 `createOnUi({ locale })` (英文除外). Props named `label`, `placeholder`, `title`,
  `description`, `…Label` 控制他们。
- **图标** 已经 Lucide 名称( E)`search`, `lucide:search`)或(或) `prefix:name` 组合中添加的 `registerIcons`.
- **链接 :** 使链接具有的组件 `linkAs` (`'a'` 默认,或 `RouterLink` / `NuxtLink`与一个
  路由器组件 URL 作为 `to`; 组件从未读取当前路由 –通过 `active`,
  `modelValue` 或 减 减 `page` 你自己来。
- **焦点环 :** 每个互动部分都显示 `shadow-focus-ring` 打开 `:focus-visible`。重叠移动焦点与
  `moveFocus`键盘导航后才会对脚本进行键盘导航(WebKit 否则会在任意一个键盘上按下键盘)
  方案重点)。
- 颜色、 光度和类型来自 `@opennavo/design-tokens`;这里没有硬码是颜色,所以主题和主题都是
  重新品牌的口音自动适用。

**使用( U)** 。用于导航,如按键通过 `href`打开/关闭设置时不要使用按钮

已禁用; 已禁用的链接将失去 `href` (或带有路由器组件的) `to`,获取 `aria-disabled="true"` 财务报告和已审计财务报表
它的点击被阻止。只显示图标的按钮必须具有 `ariaLabel`; 添加一个 `OnTooltip` 给有视力的用户。
