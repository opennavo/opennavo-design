# セキュリティポリシー

## 脆弱性の報告

公開 Issue や Pull Request で脆弱性を公開しないでください。影響を受けるパッケージ、バージョンまたはコミット、再現手順、想定される影響を **admin@opennavo.com** にお送りください。添付ファイルから認証情報と個人情報を削除してください。

安全でない HTML・URL の処理、依存関係の脆弱性、アプリのデータ漏えいに関する報告を受け付けています。架空のデータを使い、自分が管理するアプリと端末のみでテストしてください。報告者と調査・公開時期を調整しますが、対応期限は保証しません。

## サポート対象

初期プレビュー期間中の修正対象は `main` と最新リリース（存在する場合）です。古いプレビューやフォークは個別に保守しません。

## 組み込み時の責任範囲

`OnMarkdownView` はホストアプリが渡した HTML を描画します。信頼できない HTML は渡す前にサニタイズし、登録するアイコンには信頼できる SVG データだけを使ってください。データアクセス、認証、コンテンツポリシーはアプリ側の責任です。ギャラリーの言語とテーマ設定は端末内に保存されます。
