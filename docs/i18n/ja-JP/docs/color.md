# 色: 色:

すべての色はトークンから来ます。各色のトークンは暗い値(デフォルト)を持ち、それが異なる場所で、軽い値です。
とりどり [トークン参照](reference/tokens.md) このページでは、すべてのものをリストします。 このページでは、必要な役割を説明します。
適切なトークンを選ぶ。 テーマのメカニックは、 [ザミング](theming.md).

<a id="how-the-two-themes-differ"></a>

## 2つのテーマが異なる方法

- **ダーク** ステップは、明るさで表面アップ:ページ `#0B0B0B` → ベース `#131313` → カード `#1A1A1A` → 活動内容 `#262626`.
  上昇は「ライター」として読みます。
- **ライト** 同じ順序を保ちながら、白人に行くことができない:ページ `#F2F2F2` → ベース `#F8F8F8` → カード `#FFFFFF`.
  関連するパネルは、境界線と柔らかい影で白です。 ホワイトカードの中に埋めます()`cardAlt`, `raised`, `chip`)
  灰色なので、戻り値として読みます。
- ボーダーは暗モードの半透明で、ライト モードの半透明な黒、同じような強さのです。
- ブランドとステータスの色は、ライトモードがより深いため、テキストは4.5:1を白に保ちます。

1つのテーマのスクリーンショットから目で色を選ぶことはありません。 役割を選ぶ; トークンは両方の値を運びます。

## テキスト

| デザイントークン | 利用条件                                                              | ダーク            | ライト            |
| ---------------- | --------------------------------------------------------------------- | ----------------- | ----------------- |
| `text.primary`   | 見出し、強調された体、数字                                            | 14.9:1 オンカード | 17.4:1 オンカード |
| `text.secondary` | 本文、説明                                                            | 7.3:1             | 7.2:1             |
| `text.tertiary`  | ラベル、メタデータ、タイムスタンプ、ヒント                            | 5.4:1             | 5.3:1             |
| `text.disabled`  | 障害者および純粋に装飾的なテキストだけ                                | —                 | —                 |
| `text.accent`    | コーラルテキスト:リンク、サンゴチップ、強調されたインラインアクション | 6.5:1             | 5.7:1             |
| `text.inverse`   | 強い塗りつぶしのテキストとアイコン(スタタス、サンゴ、サーモン)        | ダーク            | ホワイト          |
| `text.onAccent`  | サンゴのボタンとサンゴのバッジのテキスト                              | 7.2:1 サンゴ      | サンゴの5.5:1     |

ルール:

- 1つのコンポーネントで、ほとんどの3つのテキストレベルで使用してください。 テラティアリは、ユーザーが読んでいなければならないもののフロアです。
- `text.disabled` 決して情報を運びません: 無効な制御は、それが近くにあるの理由をまだ言わなければなりません。
- **`brand.coral` テキストカラーではなく、塗りつぶしです。** 白では3.5:1です。 コーラルテキストは `text.accent`.
- 決して入れません `text.tertiary` お問い合わせ `surface.chip` または `surface.raised` 長いテキストのために;使用して下さい `text.secondary` そこに。

## チャート

一般的な色分割の不足分のために区別できる;そこにあるとき直接その順序およびラベル シリーズでそれらを使用して下さい
単品チャートの使用は2つ以上です。 `chart.emphasis` 現在の値と `chart.deemphasis` 歴史のために。
`chart.grid` そして、 `chart.axis` ヘアラインです。監視ビューは、ステータスと情報の色を意味するために使うこともできます。

<a id="do-and-dont"></a>

## やらない

- 利用する `bg-surface-popover shadow-popover border border-line-default` フローティングカードの場合、再使用しないでください。
  `surface.raised` — ライトモードではグレーです。
- トークンから半透明のスズを混ぜる()`color-mix(in srgb, var(--on-status-success) 14%, transparent)`) 時 a
  マーケティングのglowはhueを必要としています。 コンポーネント内のヘックスやrgba値を書きません。
- UIをマージする前に、両方のテーマをチェックしてください。ギャラリーとアプリは、両方の設定で切り替えます。
