# 文案

文字也是介面。同樣的規則適用於每一種語言；英文和簡體中文先寫，另外八種語言由這兩者翻譯而來，並經過審校。

## 語氣

平實、具體、沉穩——像一位能幹的朋友在解釋發生了什麼，而不是推銷員，也不是日誌檔案。

- **說清會發生什麼**。寫“Moves 14 items to the Trash. You can restore them from there.”（“將 14 個專案移到廢紙簍，之後可以從廢紙簍恢復。”），而不是“Are you sure?”（“你確定嗎？”）。
- **說清資料去向**。“Only on this Mac; nothing is uploaded.”（“只在這臺 Mac 上處理，不會上傳。”）“Search goes straight from this Mac to Apple.”（“搜尋由這臺 Mac 直接連線 Apple 完成。”）
- **承認失敗，給出下一步**。“Some content could not be loaded. Previously loaded content has been kept.”（“部分內容載入失敗，已保留上次成功載入的內容。”）“The update check could not complete. Try again, or check the network.”（“更新檢查沒有完成。請重試，或檢查網路。”）
- **不誇張，不注水**。不寫“Oops!”（“哎呀！”），不用感嘆號，也不用“simply”“just”“seamlessly”“powerful”（“只需”“輕鬆”“無縫”“強大”）這類詞。
- **具體勝過抽象**。寫明應用名、數量、大小和時間。“Docker Desktop needs administrator permission”（“Docker Desktop 需要管理員許可權”）勝過“Permission required”（“需要許可權”）。

## 措辭規則

- **按鈕**用說明動作的動詞：英文寫“Install”“Update all (4)”“Move to Trash”“Roll back”“Open in OpenNavo”，中文寫“安裝”“全部更新（4）”“移到廢紙簍”“回滾”“在 OpenNavo 中開啟”。英文的按鈕文字和選單項用標題式大小寫（title case），其餘文字都用句子式大小寫（sentence case）。
- **標題**用簡短的名詞短語或狀態：“Your list is empty”（“清單是空的”）、“No results for ‘vscode’”（“沒有找到‘vscode’的結果”）。
- **描述**只寫一句，最多兩句。先解釋，再寫操作。
- 設定下方的**提示**說明這個選項開啟後起什麼作用，而不是重複名稱已經說過的內容。
- **確認對話方塊**：標題提出具體的問題，例如“Delete ‘Work’ from this Mac?”（“要從這臺 Mac 上刪除‘Work’嗎？”）；正文說明後果；確認按鈕重複同一個動詞。
- **錯誤資訊**：用使用者能理解的話說明出了什麼問題，再說明該怎麼做。錯誤程式碼放在詳情或日誌裡，不放進標題。
- **隱私說明**以鎖形圖示開頭，並且只佔一行。
- 使用彎引號（“ ” ‘ ’）、真正的撇號（’）、省略號字元（…）和乘號（×），版本變化用箭頭（→）：`1.2.9 → 1.3.0`。
- 產品和平臺名稱保持原有拼寫：macOS、iPhone、App Store、GitHub、Homebrew。應用名稱按開發者的寫法顯示。

## 中文（簡體/繁體）

- 用自然、具體的口語書面語，不寫套話和模板句（“一站式”“全方位”“賦能”“輕鬆實現”之類）。
- 按鈕用動詞短語：“安裝”“全部更新（4）”“移到廢紙簍”。不要“確定”“好的”。
- 中文與英文、數字之間加一個半形空格：“近 30 天”“下載約 768 MB”“在 OpenNavo 中開啟”；與全形標點相鄰時不加。
- 全形標點：，。；：？！“”（）——……；引號用“”，巢狀用‘’。
- 數量用“個”“款”“項”等合適的量詞，大數用“萬”“億”（由格式化函式處理）。
- 繁體中文是獨立的語言版本：用臺灣、香港使用者熟悉的詞（“軟體”“資料夾”“設定”），不是簡體的字形轉換。

## 數字、容量和日期

始終透過共享的格式化函式（基於 `Intl`）來格式化，絕不用字串拼接：

| 型別     | 規則                                                         | 示例                         |
| -------- | ------------------------------------------------------------ | ---------------------------- |
| 數量     | 按語言區域分組；空間緊張時用緊湊形式                         | 17,392 · 1.7 萬 · 1,7 тыс.   |
| 容量     | 十進位制單位（1 KB = 1000 B），小於 10 時保留一位小數        | 768 MB · 2.3 GB              |
| 速度     | 每秒的容量                                                   | 560.6 KB/s                   |
| 百分比   | 用整數，除非小數會改變含義                                   | 62% · 0.8%                   |
| 日期     | 按語言區域的順序，月份用簡寫；當年的日期省略年份             | Oct 23 · 10月23日 · 23. Okt. |
| 相對時間 | 剛剛 → 幾分鐘前 → 幾小時前 → 昨天 → 幾天前（一週以內）→ 日期 | 2 hours ago · 昨天           |
| 時間     | 所有語言都用 24 小時制                                       | 09:00 · 21:41                |
| 時長     | 不到一分鐘時只用秒，超過後用分和秒                           | 38 s · 2 min 5 s · 2 分 5 秒 |
| 版本號   | 按釋出時的寫法；版本之間用箭頭                               | 4.49.9 → 4.50.0              |

複數使用各語言自己的複數類別（英文分 one/other；俄文分 one/few/many/other；中文和日文只有一種形式）——絕不寫 `item(s)`。

## 介面語言

| 程式碼    | 語言               | 說明                                                |
| --------- | ------------------ | --------------------------------------------------- |
| `en-US`   | English            | 措辭的原始撰寫語言；句子式大小寫                    |
| `zh-CN`   | 簡體中文           | OpenNavo 中語義的最終依據                           |
| `zh-Hant` | 繁體中文           | 使用臺灣、香港用語；日期格式遵循 `zh-TW`            |
| `ja-JP`   | 日本語             | 禮貌、簡潔；不做大寫轉換                            |
| `es-ES`   | Español            | 通常比英文長 25–35%                                 |
| `pt-BR`   | Português (Brasil) | 通常長 25–35%                                       |
| `ru-RU`   | Русский            | 通常長 30–60%；有四種複數形式                       |
| `de-DE`   | Deutsch            | 複合詞很長；要允許換行                              |
| `fr-FR`   | Français           | 冒號、分號、問號和感嘆號（: ; ? !）之前加不換行空格 |
| `it-IT`   | Italiano           | 通常長 20–30%                                       |

規則：

- **按最長的語言來設計**。13.5 px 字號下，側邊欄每項文字約有 152 px 的寬度；用俄語、西班牙語和德語對照測量，放不下就縮短譯文，而不是截斷。按鈕可以變寬；絕不固定按鈕的寬度。
- **不拼接**。使用帶命名佔位符（`{count}`、`{name}`）的完整句子，由譯者調整佔位符的位置。
- **每個語言區域都有全部的鍵**。缺失的翻譯回退到英文，CI 會檢查鍵和佔位符。
- **品牌名和產品名**不翻譯；在每種語言中，應用名都保持為 OpenNavo。
- **機器翻譯**要明確標註：內容（而不是介面）由機器自動翻譯時，要註明這一點，並附上原文連結。
