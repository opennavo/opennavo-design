# цвет

Каждый цветной токен имеет темное значение (по умолчанию) и, где он отличается, светлое значение;
тот [ссылка на токен](reference/tokens.md) Эта страница объясняет роли, которые вам нужны.
Выберите нужный токен. Механика темы [Имя](theming.md).

<a id="how-the-two-themes-differ"></a>

## Чем отличаются две темы

- **Тёмная** Шаги всплыли в легкости: страница `#0B0B0B` → основание `#131313` → карточка `#1A1A1A` → подниматься `#262626`.
  Подъем читается как «легче».
- **Светлая** Сохраняет тот же порядок, но не может быть белее белого: страница `#F2F2F2` → основание `#F8F8F8` → карточка `#FFFFFF`.
  Поднятые панели белого цвета с границей и мягкой тенью; заполняются внутри белых карточек.`cardAlt`, `raised`, `chip`)
  Они серые, поэтому читаются как утопленные.
- Границы полупрозрачные белые в темном режиме и полупрозрачные черные в светлом режиме, при аналогичной силе.
- Цвета бренда и статуса более глубокие в светлом режиме, поэтому текст сохраняет 4,5:1 на белом.

Никогда не выбирай цвет на глаз со скриншота одной темы. Выбери роль; токен несет в себе оба значения.

## Текст

| Дизайн-токен     | Использовать                                                            | Тёмная             | Светлая            |
| ---------------- | ----------------------------------------------------------------------- | ------------------ | ------------------ |
| `text.primary`   | Заголовки, выделенное тело, цифры                                       | 14.9:1 на карточке | 17.4:1 на карточке |
| `text.secondary` | Текст тела, описания                                                    | 7.3:1              | 7.2:1              |
| `text.tertiary`  | Ярлыки, метаданные, метки времени, подсказки                            | 5.4:1              | 5.3:1              |
| `text.disabled`  | Инвалидный и чисто декоративный текст                                   | —                  | —                  |
| `text.accent`    | Коралловый текст: ссылки, коралловые чипсы, подчеркнуто inline действия | 6.5:1              | 5.7:1              |
| `text.inverse`   | Текст и иконки на сильных наполнителях (статус, коралл, лосось)         | темный             | белый              |
| `text.onAccent`  | Текст на коралловых пуговицах и значках                                 | 7.2:1 на кораллах  | 5.5:1 на кораллах  |

Правила:

- Используйте не более трех уровней текста в одном компоненте. Третичная - это пол для всего, что пользователь должен прочитать.
- `text.disabled` Информацию никогда не переносит: диспетчер с ограниченными возможностями все равно должен сказать, почему он отключен поблизости.
- **`brand.coral` Это цвет, а не цвет текста.** На белом - 3.5:1. Коралловый текст использует `text.accent`.
- Никогда не ставить `text.tertiary` на `surface.chip` или `surface.raised` Длинный текст; использование `text.secondary` Вот.

## Границы

`border.subtle` для карточных краев и разделителей, `border.default` для входов, кнопок призраков и окон,

## Статус

| Семья     | Средства                                                                     | Типичное использование                                                          |
| --------- | ---------------------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| `success` | Сделано, установлено, здорово, текущее                                       | Устанавливаются значки, баннеры «Все нормально», строки журнала успеха          |

<a id="do-and-dont"></a>

## Делай и не делай

- Используйте `bg-surface-popover shadow-popover border border-line-default` для плавающей карты; не использовать повторно
  `surface.raised` — в светлом режиме он серый.
- Смешайте полупрозрачные оттенки из токенов (`color-mix(in srgb, var(--on-status-success) 14%, transparent)`) когда а
  Маркетинговое свечение нуждается в оттенке; не записывайте значения гекса или rgba в компонентах.
- Проверьте обе темы перед слиянием пользовательского интерфейса; галерея и приложение переключаются с одной настройкой.
