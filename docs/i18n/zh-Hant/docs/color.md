# 顏色

所有顏色都來自令牌。每個顏色令牌都有一個深色值（預設值），與深色不同時還有一個淺色值；[令牌參考](reference/tokens.md)列出了全部令牌。本頁說明各個令牌的角色——選對令牌，靠的就是了解角色。主題的實現機制見[主題](theming.md)。

## 兩套主題的區別

- **深色**主題按亮度逐級抬高表面：page `#0B0B0B` → base `#131313` → card `#1A1A1A` → raised `#262626`。層級越高，看起來越亮。
- **淺色**主題保持同樣的順序，但不可能比白色更白：page `#F2F2F2` → base `#F8F8F8` → card `#FFFFFF`。高層級的面板是白色，加邊框和柔和的陰影；白色卡片裡的填充（`cardAlt`、`raised`、`chip`）是灰色，所以看起來是凹進去的。
- 邊框在深色模式下是半透明白色，在淺色模式下是半透明黑色，強度相近。
- 品牌色和狀態色在淺色模式下更深，以保證文字在白底上仍有 4.5:1 的對比度。

不得照著某一套主題的截圖憑肉眼取色。要選角色，令牌會同時帶上兩套取值。

## 表面

| 令牌              | 角色             | 用於                                                                            | 不用於                             |
| ----------------- | ---------------- | ------------------------------------------------------------------------------- | ---------------------------------- |
| `surface.page`    | 最外層背景       | 網站頁面主體、頂部導航欄、浮動視窗背後的區域                                    | 應用外殼內的內容區                 |
| `surface.base`    | 主內容背景       | 應用外殼的內容欄、視窗背景                                                      | 卡片                               |
| `surface.sidebar` | 側邊欄           | 左側導航欄                                                                      | 其他任何地方                       |
| `surface.rail`    | 右側欄           | 寬視窗中可選的統計右側欄                                                        | —                                  |
| `surface.card`    | 卡片和麵板       | 卡片、列表容器、設定分組、選單欄浮窗                                            | 浮在內容之上的面板（用 `popover`） |
| `surface.cardAlt` | 卡片內部         | 輸入框、次級區塊、表格行高亮、卡片內的提示框                                    | 頁面級背景                         |
| `surface.raised`  | 懸停和小面積填充 | 懸停背景、分頁中的當前頁、圖示底塊、`⌘K` 提示                                   | 浮動面板；選中的分段               |
| `surface.chip`    | 中性徽標         | 中性標籤（chip）、快捷鍵提示、小標籤                                            | 按鈕（用 `button.secondary*`）     |
| `surface.control` | 控制元件         | 設定中的文字輸入框和下拉選擇框、懸停提示                                        | 大面積區域                         |
| `surface.inset`   | 凹槽             | 程式碼塊、日誌、分段控制元件的軌道、進度條軌道                                  | 按鈕                               |
| `surface.overlay` | 半透明浮層       | 選單和命令面板，配合 20 px 的背景模糊                                           | 不透明面板                         |
| `surface.popover` | 浮動面板         | 隱私授權卡片和建議卡片、演示用浮窗——凡是帶 `shadow.popover`、浮在內容之上的元素 | 頁面流中的內容                     |

元件專用的表面放在 `component.*` 下：`modalBg` 用於對話方塊和側邊面板（sheet），`searchBg` 用於搜尋框和頁面中的表單輸入框，`navActive` 用於選中的側邊欄專案，`segmentActive` 用於選中的分段，`heroBg` 用於功能主視覺；此外還有 `detailHeaderBg`、`toastBg`、`scrim`（對話方塊背後的遮罩）、`lightboxScrim`（圖片檢視器的遮罩，兩套主題下都是深色，所以檢視器整體用深色主題渲染，見[主題 › 區域性主題](theming.md#區域性主題)），以及 `menuBarBg` / `menuBarText`（應用內模擬的 macOS 選單欄）。

## 文字

| 令牌             | 用途                                             | 深色           | 淺色           |
| ---------------- | ------------------------------------------------ | -------------- | -------------- |
| `text.primary`   | 標題、需要強調的正文、數字                       | 卡片上 14.9:1  | 卡片上 17.4:1  |
| `text.secondary` | 正文、描述                                       | 7.3:1          | 7.2:1          |
| `text.tertiary`  | 欄位名、元資訊、時間戳、提示                     | 5.4:1          | 5.3:1          |
| `text.disabled`  | 只用于禁用狀態和純裝飾性的文字                   | —              | —              |
| `text.accent`    | 珊瑚色文字：連結、珊瑚色標籤、需要強調的行內操作 | 6.5:1          | 5.7:1          |
| `text.inverse`   | 強填充色（狀態色、珊瑚色、鮭魚色）上的文字和圖示 | 深色           | 白色           |
| `text.onAccent`  | 珊瑚色按鈕和珊瑚色徽標上的文字                   | 珊瑚色上 7.2:1 | 珊瑚色上 5.5:1 |

規則：

- 一個元件裡最多用三級文字。使用者必須讀到的內容，最低只能用 `text.tertiary` 這一級。
- `text.disabled` 絕不承載資訊：禁用的控制元件必須在附近說明為什麼不可用。
- **`brand.coral` 是填充色，不是文字顏色**。它在白底上只有 3.5:1。珊瑚色文字用 `text.accent`。
- 不得把 `text.tertiary` 放在 `surface.chip` 或 `surface.raised` 上排長文字，這些背景上改用 `text.secondary`。

## 邊框

`border.subtle` 用於卡片邊緣和分隔線，`border.default` 用於輸入框、幽靈按鈕和視窗，`border.strong` 用於懸停狀態。`border.sidebar` 用來分隔側邊欄。狀態面板使用對應的 `status.*Border`，配合同色系的 `status.*Subtle` 填充。

## 品牌色

| 令牌                                           | 用途                                                                             |
| ---------------------------------------------- | -------------------------------------------------------------------------------- |
| `brand.coral`                                  | 作為填充或圖形使用的品牌強調色：強調按鈕、進度、開啟狀態的開關、焦點環、小圓點。 |
| `brand.salmon`                                 | 暖色的強調文字：區塊眉題、主視覺標題的第二行、“有可用更新”徽標。                 |
| `brand.violet`                                 | 主視覺光暈；營銷頁面上帶色調的圖示背景中也會混入這種顏色。                       |
| `brand.logoGradient`、`brand.logoCoreGradient` | 只用於 Logo 標誌。在淺色背景上，核心漸變改為琥珀色。                             |

強調色的淡色版本：`accent.coralSubtle`（進度條軌道、珊瑚色標籤）和 `accent.salmonSubtle`（鮭魚色徽標）。疊在它們上面的文字分別用 `text.accent` 和 `brand.salmon`。

珊瑚色要剋制地使用：每個檢視只放一個強調按鈕，並且絕不用珊瑚色表示錯誤（錯誤用 `status.danger`）。

## 狀態色

| 色系      | 含義                                       | 典型用法                                       |
| --------- | ------------------------------------------ | ---------------------------------------------- |
| `success` | 已完成、已安裝、正常、已是最新             | “已安裝”徽標、“一切正常”橫幅、成功的日誌行     |
| `warning` | 需要注意、需要管理員許可權、只得到部分結果 | 已跳過的專案、管理員許可權提示、“需要確認”標籤 |
| `danger`  | 失敗、已棄用、破壞性                       | 失敗狀態、危險按鈕、發現的威脅                 |
| `info`    | 中性資訊、可自行更新的應用、文件中的連結   | 資訊提示框、“自動更新”標籤                     |

每個色系都有一個純色（用於文字、圖示、圓點）、`*Subtle`（10% 濃度的淡色背景）和 `*Border`（帶色調的面板邊框）。顏色要搭配圖示或文字一起使用——狀態絕不只靠顏色傳達。

## 按鈕

| 變體 | 令牌                                              | 用途                                                                 |
| ---- | ------------------------------------------------- | -------------------------------------------------------------------- |
| 主要 | `button.primary*`——深色下接近白色，淺色下接近黑色 | 檢視的主操作。每個區域一個。                                         |
| 次要 | `button.secondary*`                               | 其他操作。預設變體。                                                 |
| 強調 | `button.accent*`（珊瑚色，深色文字）              | 體現品牌的時刻：主視覺區的行動按鈕、“全部更新”。一屏裡很少超過一個。 |
| 幽靈 | 透明，`border.default`                            | 工具欄和緊湊行中的第三級操作。                                       |
| 危險 | `status.dangerSubtle` + `status.danger`           | 破壞性操作。絕不作為對話方塊的預設按鈕。                             |
| 禁用 | `button.disabled*`                                | 任意變體的不可用狀態。                                               |

## 圖表

`chart.series1`（紫色）、`chart.series2`（珊瑚色）、`chart.series3`（綠色）是分類色，選色時確保有常見色覺障礙的人也能區分；按這個順序使用，系列超過兩個時，直接在圖上標註系列名稱。單系列圖表用 `chart.emphasis` 表示當前值，用 `chart.deemphasis` 表示歷史值。`chart.grid` 和 `chart.axis` 都是細線。監控檢視也可以用狀態色和資訊色表達含義（溫度警告、網路下載/上傳）。

## 對比度

按 WCAG 2.2 的公式計算；任何一組顏色低於目標值，`packages/tokens/tests` 都會讓構建失敗。

| 前景色                    | 目標值 | 深色（base / card / raised） | 淺色（base / card / raised） |
| ------------------------- | ------ | ---------------------------- | ---------------------------- |
| `text.primary`            | 4.5    | 15.9 / 14.9 / 12.9           | 16.4 / 17.4 / 14.9           |
| `text.secondary`          | 4.5    | 7.8 / 7.3 / 6.4              | 6.8 / 7.2 / 6.2              |
| `text.tertiary`           | 4.5    | 5.7 / 5.4 / 4.7              | 5.0 / 5.3 / 4.6              |
| `text.accent`             | 4.5    | 6.9 / 6.5 / 5.6              | 5.4 / 5.7 / 4.9              |
| `brand.salmon`            | 4.5    | 9.0 / 8.4 / 7.3              | 5.4 / 5.7 / 4.9              |
| `status.success`          | 4.5    | 9.2 / 8.6 / 7.5              | 5.3 / 5.6 / 4.8              |
| `status.warning`          | 4.5    | 10.1 / 9.5 / 8.2             | 5.3 / 5.6 / 4.8              |
| `status.danger`           | 4.5    | 6.1 / 5.7 / 5.0              | 5.4 / 5.7 / 4.9              |
| `status.info`             | 4.5    | 7.3 / 6.8 / 5.9              | 5.3 / 5.6 / 4.8              |
| `brand.coral`（用作圖形） | 3.0    | 6.9 / 6.5 / 5.6              | 3.3 / 3.5 / 3.0              |

測試還覆蓋了：狀態色和強調色文字疊在各自淡色背景上的情況（淡色背景分別疊在 base、card 和 cardAlt 之上）、每種按鈕狀態、珊瑚色上的文字、終端圖示，以及凹槽中的等寬文字。

## 該做與不該做

- 浮動卡片用 `bg-surface-popover shadow-popover border border-line-default`；不要複用 `surface.raised`——它在淺色模式下是灰色的。
- 營銷頁面的光暈需要某種色相時，用令牌混出半透明色調（`color-mix(in srgb, var(--on-status-success) 14%, transparent)`）；不要在元件裡寫十六進位制或 rgba 值。
- 合併介面改動之前，兩套主題都要檢查；元件預覽頁和應用都只需改一個設定就能切換主題。
