# 構成部分

每一組成部分的參考文獻 [`@opennavo/design-vue`](../../../../packages/vue):它的目的是什麼,它的道具,事件和
插槽(如來源中宣告的),變體,何時使用,以及鍵盤和輔助技術的表現.
元件組合成螢幕的方式 [圖案](patterns.md); 畫廊(`pnpm gallery`) 顯示
在兩個主題和所有十種語言中都有變體。不使用的 Apps Vue 遵循同樣的解剖學,大小和狀態
直接用符號表示([平臺](platforms.md)).

公約:

- **預設** `—` 表示道具是可選和未設定的;沒有列出預設的布林道具是 `false`.
- 內建字串("Close","Pagination","Search"...)來源於該包在本地域的資訊目錄
  給 `createOnUi({ locale })` (英文除外). Props named `label`, `placeholder`, `title`,
  `description`, `…Label` 控制他們。
- **圖示** 已經 Lucide 名稱( E)`search`, `lucide:search`)或(或) `prefix:name` 組合中新增的 `registerIcons`.
- **連結 :** 使連結具有的元件 `linkAs` (`'a'` 預設,或 `RouterLink` / `NuxtLink`與一個
  路由器元件 URL 作為 `to`; 元件從未讀取當前路由 –透過 `active`,
  `modelValue` 或 減 減 `page` 你自己來。
- **焦點環 :** 每個互動部分都顯示 `shadow-focus-ring` 開啟 `:focus-visible`。重疊移動焦點與
  `moveFocus`鍵盤導航後才會對指令碼進行鍵盤導航(WebKit 否則會在任意一個鍵盤上按下鍵盤)
  方案重點)。
- 顏色、 光度和型別來自 `@opennavo/design-tokens`;這裡沒有硬碼是顏色,所以主題和主題都是
  重新品牌的口音自動適用。

**使用( U)** 。用於導航,如按鍵透過 `href`開啟/關閉設定時不要使用按鈕

**無障礙.** 一個本地人 `<button>` (包含鍵盤和窗體行為)或連結。已禁用的按鈕是本地的
已禁用; 已禁用的連結將失去 `href` (或帶有路由器元件的) `to`,獲取 `aria-disabled="true"` 財務報告和已審計財務報表
它的點選被阻止。只顯示圖示的按鈕必須具有 `ariaLabel`; 新增一個 `OnTooltip` 給有視力的使用者。
