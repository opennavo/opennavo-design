# 互動模式

本篇講元件如何組合成頁面。每個模式都寫明瞭用到的元件，元件細節見[元件](components.md)（暫為英文）。

## 導航

- **側邊欄**（`OnSidebar`、`OnNavItem`）：最上方是品牌標誌，然後是若干分組，每組有一個 `text-label` 標題（瀏覽、清單、工具、我的……），設定固定在最下方。當前項使用 `component.navActive` 和 `aria-current="page"`。數量靠右對齊，使用 `text-ink-tertiary`；需要使用者注意的數量改用珊瑚色徽標；只提示“有新內容”、不需要數字時，用一個圓點。
- **工具欄**（`OnToolbar`）：桌面應用中，左側是後退/前進和重新整理（網頁上由瀏覽器提供），右側是帶 `⌘K` 提示的搜尋入口，再往右是全域性開關（主題；網頁上還有語言）。
- **命令面板**（`OnCommandPalette`，`⌘K` / `Ctrl K`）：操作和跳轉目標排在前面，第一行是“See all results for ‘q’”（“檢視‘q’的全部結果”），按 Enter 開啟完整的結果頁；其餘條目排在下面。方向鍵移動，Enter 開啟，Escape 關閉並把焦點還給原來的位置。
- **標籤頁**（`OnTabs`）用來切換同一物件的不同檢視（例如一個應用的概覽、版本、依賴、詳情）；每個檢視有自己的 URL 時，標籤頁就是連結。**分段控制元件**（`OnSegmented`）用於在檢視內部篩選或切換模式（時間段、排序、“全部/成功/失敗”）。
- **麵包屑**（`OnBreadcrumb`）出現在從列表進入的詳情頁上。
- 每個檢視都有 URL（桌面端的路由也一樣），這樣深層連結、後退/前進和恢復都能正常工作。

## 頁面結構

1. 頁面頭部（`OnPageHeader`）：`text-title1` 標題；一行次要文字，寫出關鍵資訊（數量、上次檢查時間）；頁面操作靠右對齊（主要操作放在最後）。
2. 檢視功能受限時（離線、部分失敗），可以在頁面頭部正下方放一條橫幅。
3. 區塊（`OnSectionHeader`）：`text-headline` 標題，一行簡短的副標題（三級文字），右側放“檢視全部 →”。
4. 右側欄（`OnRailPanel`、`OnRailSection`）承載摘要和次要操作；在主內容欄完成任務時，不需要用到右側欄裡的任何內容。

## 列表、卡片和表格

- **卡片**用於瀏覽（圖示、名稱、一行摘要、兩三個統計數字、一個操作）。整張卡片就是連結；卡片裡的操作按鈕要阻止事件冒泡。
- **行**用於需要逐項操作的緊湊列表（更新、歷史記錄、已安裝的應用）：左側是圖示、名稱和元資訊，中間是狀態標籤（chip），右側是操作；破壞性操作放在行的⋯選單裡。
- **表格**（`OnTable`）用於需要按列比較或排序的場合；數字列右對齊，並使用 `tabular-nums`；勾選框放在第一列；長表格的表頭固定。
- 長列表用分頁（`OnPagination`），不用無限滾動，這樣當前位置可以被連結，也保持穩定。
- **調整條件時保留內容**：查詢、排序、篩選條件或頁碼變化時，繼續顯示之前的結果（必要時調暗），直到新結果到達；為可選的計數行預留位置，避免內容跳動。

## 搜尋

- 工具欄裡的搜尋入口開啟命令面板；搜尋頁顯示完整結果，篩選項用分段控制元件或標籤呈現。
- 使用者輸入時結果實時更新，中途不清空；“No results for ‘q’”（“沒有找到‘q’的結果”）要附帶一條具體的建議（換一種拼寫、用英文名、換一個來源）。

## 設定和表單

- 設定按卡片分組，每張卡片由若干行組成（`SettingRow` 模式）：左側是名稱和可選的一行提示，右側是控制元件，行與行之間用 `border.subtle` 分隔。
- **改動立即生效**——開關、分段控制元件、選單都是如此。設定裡沒有“儲存”按鈕；某項改動失敗時，恢復原值，並用輕提示（toast）說明原因。
- 按選項數量選擇控制元件：開/關用開關，兩到四個互斥選項用分段控制元件，更長的列表（比如語言）用選單，並勾選當前選項。
- 文字輸入在失去焦點或提交時校驗，絕不在每次按鍵時校驗；錯誤用 `text-status-danger` 顯示在欄位下方，並寫明怎麼改，例如“Use a full https:// address”（“請填寫 https:// 開頭的完整地址”）；欄位保留已輸入的值。
- 網頁上的表單只有一欄，欄位標題在輸入框上方；必填欄位全部有效之前，提交按鈕保持禁用，並用提示說明還缺什麼。

## 反饋

| 場景                                 | 用法                                                                     |
| ------------------------------------ | ------------------------------------------------------------------------ |
| 操作已完成（已複製、已新增、已安裝） | 輕提示，成功或中性樣式，4 s 後自動消失，懸停時暫停計時                   |
| 操作失敗                             | 輕提示，寫明原因；可能的話附帶一個操作（重試、檢視日誌）                 |
| 檢視功能受限（離線、資料不完整）     | 頁面頭部下方的橫幅，說明哪些功能仍然可用                                 |
| 需要使用者做決定                     | 對話方塊（`OnConfirm`、`OnModal`）                                       |
| 正在執行長任務                       | 就地顯示進度（行、卡片或任務面板）；如果任務轉到後臺繼續，選單欄裡也顯示 |
| 視窗關閉期間發生了某件事             | 系統通知，僅在使用者開啟通知時傳送                                       |

同時最多顯示三條輕提示；失敗會立即向讀屏軟體播報（`role="alert"`），其餘的以禮貌模式（polite）播報。

## 破壞性操作和改動系統的操作

1. 說清會發生什麼，並列出將被移除或改動的內容及其大小。
2. 預設選可恢復的方式：移到廢紙簍；停用登入項，而不是刪除；保留回滾的餘地。
3. 確認按鈕寫明動作，例如“Uninstall”（“解除安裝”）、“Move 14 items to Trash”（“將 14 個專案移到廢紙簍”），並使用危險樣式；預設焦點放在“取消”上。
4. 操作之後：結果立即就地顯示；可以撤銷時，彈出帶“撤銷”的輕提示；同時在歷史記錄中留下一條記錄。
5. 需要管理員許可權的操作，開始之前就要說明；密碼提示框要寫明用途。

## 載入、進度和結果

- 檢視首次載入：使用形狀與內容一致的骨架屏（`OnSkeleton`），不要整頁顯示載入轉圈。
- 重新整理、調整條件、後臺重新載入：保留當前內容，最多顯示一個小小的進度提示。
- 長任務一有數字（位元組數、專案數）就顯示確定進度，並用文字說明當前步驟；取消不會造成問題時，允許使用者取消。日誌可以檢視，但預設摺疊。
- **結果即時呈現**：任務一結束，所有顯示該物件的地方（行、詳情頁、側邊欄計數、選單欄）都立即用任務自身的結果更新，而不是等到下一次定時重新整理。

## 空狀態、錯誤和離線

- **空狀態**（`OnEmpty`）：一個圖示；一個簡短的標題，例如“Your list is empty”（“清單是空的”）；一句話說明怎樣把它填滿；有對應的操作時，再放上這個操作。
- **錯誤**（`OnErrorState`）：用平實的話說明什麼失敗了，提供“重試”，不顯示堆疊資訊；原本有內容的檢視重新整理失敗時，改為顯示橫幅並保留內容。
- **離線**（`OnOffline`）：快取的內容仍然可用；需要聯網的功能，在它本該出現的位置說明這一點。

## 許可權

- 在真正需要的時候再申請許可權，用一句話說明原因，以及哪些內容會保持私密。
- “開啟”會開啟系統設定中對應的面板；一個小的浮動引導會說明要拖動或開啟什麼，並且不會搶走系統設定的焦點。
- 使用者回來後，檢視會重新檢查並自動繼續；如果 macOS 要求重新啟動應用，檢視會說明這一點並提供重啟選項。
- 絕不糾纏使用者：使用者拒絕授權後，只留下一行帶“開啟”按鈕的安靜提示，而不是反覆彈出對話方塊。

## 選單欄專案和浮窗（macOS）

- 選單欄專案使用模板影象，畫法與系統專案一致；文字和圖表遵循系統選單欄的樣式。
- 點選專案會在其下方開啟浮窗；再次點選或點選其他任何地方即關閉。浮窗絕不啟用主視窗，也絕不搶走使用者當前所用應用的焦點。
- 浮窗是緊湊的卡片（`surface.card`、`rounded-panel`），放最有用的三到五行內容、一個主要操作，以及一個在主視窗中開啟完整檢視的連結。

## 新手引導

只用一個檢查清單頁面：每項要求佔一行，包含狀態圖示、這項要求是什麼，以及修復操作；必需的各行全部透過後，主按鈕“開始使用”才可點選，在此之前用一句話說明還缺什麼。可選步驟可以跳過，之後也能在設定裡找到。

## 網站專屬規則

- 網站絕不要求註冊賬號。每位訪客各自的選擇（主題、隱私授權、語言建議、儲存的清單）都存在瀏覽器裡。
- “在應用中開啟”連結會請桌面應用先展示它將要做什麼；對於網頁發起的任何請求，應用在執行之前都會先請使用者確認。
- 語言建議只出現一次，可以關閉，並且絕不自行跳轉。
