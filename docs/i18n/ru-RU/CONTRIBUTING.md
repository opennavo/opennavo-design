## Основные правила

- **Сначала токены.** Изменения `tokens/tokens.json`Беги. `pnpm gen`, соединять сгенерированные файлы с изменением.
  Редактировать файл с пометкой generated .
- **Обе темы.** Каждый новый цвет имеет темный `value` Если же он различается, то `light` Добавить или обновить
  Контрастный тест для любой новой пары текста/фона (`packages/tokens/tests`).
- **Роли, а не внешность.** Если существующий токен имеет правильный цвет, но неправильную работу, добавьте токен для работы.
  ([docs/principles.md](docs/principles.md#rules-that-settle-arguments)).
- **Компоненты остаются общими.** Никаких названий продуктов, форм данных о продукте или сетевых вызовов. `packages/vue`; Приложения проходят
  Содержание через реквизит и слоты.
- **Док двигается с кодом.** Новый токен, опция компонента или поведение обновляет соответствующую страницу в `docs/`.
- **Сначала английский.** Документация, комментарии к источникам, ошибки и инструментальные средства разработчика по умолчанию на английском языке.`en-US`) является исходным языком для компонентных строк; сохранять явно локализованный контент.
- **Десять языков.** Новые строки компонентов входят во все десять файлов сообщений `packages/vue/src/messages`Английский язык остается по умолчанию; не выводите язык из настроек браузера.

<a id="translations-and-previews"></a>

## Переводы и предварительные просмотры

Английский язык является источником для всех десяти языков: `en-US`, `zh-CN`, `zh-Hant`, `ja-JP`, `es-ES`, `pt-BR`, `ru-RU`,
`de-DE`, `fr-FR` и `it-IT`Компонентные сообщения живут в `packages/vue/src/messages`; галереи сообщений живут в
`packages/vue/gallery/src/messages`Переведите видимую копию истории, а также навигацию и доступные этикетки.
Сохраняйте имена компонентов, числовые значения, URL-адреса, образцы кода и оригиналы лицензий без изменений.

Зеркала с полной документацией живут в `docs/i18n/<locale>/`Следуя английским репозиториям.
Новые переводы начинаются с автономных машинных проектов и нуждаются в языковом обзоре, особенно техническом и юридическом.
Проза. Английский язык остается авторитетным. Обзор бразильского португальского словаря отдельно от общего португальского.
При изменении английского языка обновите соответствующие файлы на каждом языке, а затем запишите SHA-256 на английском языке.
`docs/i18n/manifest.json`Беги. `pnpm check:i18n` для проверки покрытия, свежести источника, ссылок и примеров кода.
Не обновляйте манифест только для того, чтобы заставить замолчать неудачу без обновления переводов.

Читать скриншоты в `docs/previews` показать вымышленные образцы данных из реальной галереи.
Использование браузера на задокументированной теме и языке, без хрома браузера или личной информации.
