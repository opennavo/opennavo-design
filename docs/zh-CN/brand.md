# 品牌

> 英文原文：[brand.md](../brand.md)。两者不一致时以英文版为准。

OpenNavo Design 由一系列应用共用。它们除了一层很薄的品牌层之外，其他一切都相同，所以熟悉其中一个应用的人，也就熟悉了其他应用。

## 品牌层

应用只能修改以下令牌（两套主题的值都要给）：

| 令牌                                                                                 | 承载的内容                                                     |
| ------------------------------------------------------------------------------------ | -------------------------------------------------------------- |
| `brand.coral`                                                                        | 强调色填充：强调按钮、打开状态的开关、进度、焦点环颜色、小圆点 |
| `text.accent`                                                                        | 强调色文字和链接                                               |
| `accent.coralSubtle`                                                                 | 标签（chip）和进度条轨道背后的强调色淡色                       |
| `button.accentBg`、`button.accentHover`、`button.accentPressed`、`button.accentText` | 强调按钮                                                       |
| `shadow.focusRing`                                                                   | 焦点环（保持“2 px 间隙 + 2 px 环”的形状）                      |
| `component.runningBorder`                                                            | 运行中任务的边框                                               |
| `brand.salmon`、`accent.salmonSubtle`                                                | 暖色的强调文字和徽标                                           |
| `brand.violet`、`effect.heroGlow`、`effect.coverGlow`                                | 主视觉光晕                                                     |
| `brand.logoGradient`、`brand.logoCoreGradient`                                       | 应用自己的标志                                                 |

令牌名称保持不变（即使某个应用的强调色是蓝色，`brand.coral` 也沿用这个名字），这样组件和文档都不会分叉。用覆盖文件生成应用的令牌（[主题 › 换品牌](theming.md#为其他应用换品牌)），并保证对比度测试全部通过：两套主题下，强调色文字仍必须达到 4.5:1，强调色填充必须达到 3:1。

除此之外的一切——中性色、状态色、字体、间距、圆角、动效、组件和交互模式——在每个应用中都相同。

## 名称和标志

- 每个应用有自己的名称和标志。组件通过 `brand` 插槽接收标志；设计系统本身不附带任何 Logo。
- OpenNavo 的名称和 Logo 是 OpenNavo 作者的商标，**不在**本仓库 MIT 许可的范围内（[TRADEMARKS.md](../../TRADEMARKS.md)）。基于本系统构建的应用不得把它们用作自己的名称或图标。
- 组件前缀 `On` 和 CSS 前缀 `--on-` 属于设计系统，而不属于某个产品；请保留它们。

## 标志的正确用法（OpenNavo 自身）

- 字标放在标志旁边，字号 15 px、字重 600、颜色为 `brand.coral`；旁边的标志高 22 px。
- 小于 32 px 时，标志使用简化后的图形。四周至少留出标志高度一半的空白。
- 在浅色背景上，标志中的星形改用琥珀色核心渐变；不得把标志放在杂乱的图片上。
