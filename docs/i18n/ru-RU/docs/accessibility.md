# Доступность

Цель - это WCAG 2.2 АА в обеих темах. Большая часть его встроена в токены и компоненты; на этой странице перечислены
Приложения не должны отменяться.

<a id="contrast"></a>

## контраст

- Текст 4.5:1 на его фактическом фоне, включая тонированные значки и заливки; большой текст отображения (24 px +, или
  19 px + при 600) 3:1 Тесты токенов обеспечивают соблюдение пар в [Цвет › контраст](color.md#contrast).
- Иконки, несущие смысл, отметки диаграмм, границы входа и фокусное кольцо: 3:1.
- Декоративный текст (`text.disabled`, водяные знаки) не несет никакой информации.

<a id="keyboard"></a>

## Клавиатура

- Все, что доступно Tab в визуальном порядке, не является невидимым.
- **Кольцо фокусировки:** `shadow-focus-ring` на `:focus-visible` - 2-х кратный разрыв в цвете поверхности плюс 2-х коралловое кольцо.
  Никогда не удаляйте его без эквивалента.
- **Композитные виджеты** использование скользящего фокуса (одна остановка Tab, стрелки внутри): сегментированные элементы управления`radiogroup`), вкладки
  (`tablist`), чип-бары, меню (`menu` с `menuitem` / `menuitemradio`), командная палитра (`combobox` +
  `listbox`).
- **Наложения** перемещайте фокус внутри на открытую, ловушку Tab, закройте Escape и верните фокус на элемент, который их открыл.
  Фокус, перемещаемый по сценарию, не показывает кольцо, когда пользователь открывает наложение указателем.
- **ярлыки** Следуйте за платформой (поиск theK, the, настройки, theF найти в виде, Escape обратно) и показаны в
  Меню и подсказки никогда не требуются.

<a id="pointer-and-touch"></a>

## Пойнтер и сенсор

- Целевые значения не менее 24 × 24 px в плотном пользовательском интерфейсе рабочего стола, 32 px для первичных элементов управления, 44 px для первичных мобильных веб-действий.
- Hover не показывает ничего, чего не могут достичь пользователи клавиатуры и сенсорных устройств.
