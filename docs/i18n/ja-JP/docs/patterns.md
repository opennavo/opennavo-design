# パターン

コンポーネントがスクリーンに結合する方法。各パターンは、使用するコンポーネントの名前を指しています。その詳細は、
[コンポーネント](components.md).

<a id="navigation"></a>

## ナビゲーション

- **サイドバー** (`OnSidebar`, `OnNavItem`): ブランド マーク、そしてグループと `text-label` タイトル(参照、リスト、ツール、
  鉱山...)、それから底でピン留められる設定。現在の項目は使用します `component.navActive` そして、 `aria-current="page"`.
  カウントは右揃えで座ります `text-ink-tertiary`; 注意が必要なカウントはサンゴのバッジになります; 点マーク
  「何か新しい」を数えずに。
- **ツールバー** (`OnToolbar`): デスクトップアプリの左側にバック/フォワードおよびリロード(ブラウザはそれらを提供します
  web)、検索トリガーとその `⌘K` その後、グローバルスイッチ(テーマ、Web上の言語)をヒントにします。
- **コマンドパレット** (`OnCommandPalette`, `⌘K` / `Ctrl K`): 最初に行動および目的地、と
  "q" の全ての結果は最初の行として表示されます(完全な結果ページを開く)。下の項目。矢印キーの移動、入力
  開いた、エスケープは焦点を閉まり、戻します。
- **タブ** (`OnTabs`) 1つのオブジェクト(アプリの概観、バージョン、依存関係、詳細)のビューを切り替え、リンク
  各ビューに独自のURLがある場合。 **セグメント制御** (`OnSegmented`) フィルターかスイッチはビューの中のモードを(period、
  「すべて/成功/失敗」をソートします。
- **パン粉** (`OnBreadcrumb`) リストから到達した詳細ページに表示されます。
- すべてのビューには、URL(デスクトップのルートを含む)が含まれているので、深いリンク、バック/フォワード、復元作業があります。

<a id="page-anatomy"></a>

## ページの解剖学

1. ページのヘッダー (`OnPageHeader`): `text-title1` タイトル、キーファクト(counts, last)で二次テキストの1行
   チェック), ページのアクションを右揃え (プライマリ最後の).
2. ヘッダーの下の直接劣化状態(オフライン、部分的な故障)のオプションバナー。
3. セクション (`OnSectionHeader`): `text-headline` タイトル、短いtertiaryサブタイトル、右上の「すべてを表示する →」。
4. レール (`OnRailPanel`, `OnRailSection`) 要約および二次行為を運びます;柵で何も必要としません
   メインの列でタスクを完了します。

<a id="lists-cards-and-tables"></a>

## リスト、カード、テーブル

- **カード** ブラウジング(アイコン、名前、ワンラインサマリー、2または3つのスタッツ、1つのアクション)。カード全体がリンクです。
  アクションボタンを内部で停止します 伝搬.
- **ルーズ** dense リストのために(更新、履歴、インストールされたアプリ): アイコン、名前、左のメタ、状態の破片
  途中で、右にアクションを実行します。 破壊的なアクションは、行の [テキスト] メニューに住んでいます。
- **テーブル** (`OnTable`) カラムが比較またはソートされる場合、数値列は右揃え `tabular-nums`;
  最初の列で選択チェックボックス; 長いテーブルの粘着性のヘッダー。
- 長いリストを Paginate ()`OnPagination`) 無限スクロールではなく、位置がリンク可能で安定しています。
- **精製はコンテンツを保持します。:** クエリ、ソート、フィルタ、ページの変更中に、前の結果を表示し続ける(調光)
  必要であれば)新しいものが到着するまで、オプションのカウントラインの空き容量が確保されるため、シフトは発生しません。

## ローディング、進捗状況および結果

- リフレッシュ、洗練、背景リロード:現在のコンテンツを保持します。 ほとんどの小さな進捗ヒント。
- 長いタスクは、単語の現在のステップで、数字が(バイト、項目)存在するとすぐに進捗を非正規化表示します。
  キャンセルは安全です。ログは利用できますが、破棄されます。
- **結果は一度に解決します:** タスクが終了すると、オブジェクト(row、詳細ページ、サイドバー)を示すすべての場所
  カウント、メニューバー)は、次の周期的なリフレッシュの後にではなく、タスク自身の結果からすぐに更新されます。
