# 文案

文字也是界面。同样的规则适用于每一种语言；英文和简体中文先写，另外八种语言由这两者翻译而来，并经过审校。

## 语气

平实、具体、沉稳——像一位能干的朋友在解释发生了什么，而不是推销员，也不是日志文件。

- **说清会发生什么**。写“Moves 14 items to the Trash. You can restore them from there.”（“将 14 个项目移到废纸篓，之后可以从废纸篓恢复。”），而不是“Are you sure?”（“你确定吗？”）。
- **说清数据去向**。“Only on this Mac; nothing is uploaded.”（“只在这台 Mac 上处理，不会上传。”）“Search goes straight from this Mac to Apple.”（“搜索由这台 Mac 直接连接 Apple 完成。”）
- **承认失败，给出下一步**。“Some content could not be loaded. Previously loaded content has been kept.”（“部分内容加载失败，已保留上次成功加载的内容。”）“The update check could not complete. Try again, or check the network.”（“更新检查没有完成。请重试，或检查网络。”）
- **不夸张，不注水**。不写“Oops!”（“哎呀！”），不用感叹号，也不用“simply”“just”“seamlessly”“powerful”（“只需”“轻松”“无缝”“强大”）这类词。
- **具体胜过抽象**。写明应用名、数量、大小和时间。“Docker Desktop needs administrator permission”（“Docker Desktop 需要管理员权限”）胜过“Permission required”（“需要权限”）。

## 措辞规则

- **按钮**用说明动作的动词：英文写“Install”“Update all (4)”“Move to Trash”“Roll back”“Open in OpenNavo”，中文写“安装”“全部更新（4）”“移到废纸篓”“回滚”“在 OpenNavo 中打开”。英文的按钮文字和菜单项用标题式大小写（title case），其余文字都用句子式大小写（sentence case）。
- **标题**用简短的名词短语或状态：“Your list is empty”（“清单是空的”）、“No results for ‘vscode’”（“没有找到‘vscode’的结果”）。
- **描述**只写一句，最多两句。先解释，再写操作。
- 设置下方的**提示**说明这个选项开启后起什么作用，而不是重复名称已经说过的内容。
- **确认对话框**：标题提出具体的问题，例如“Delete ‘Work’ from this Mac?”（“要从这台 Mac 上删除‘Work’吗？”）；正文说明后果；确认按钮重复同一个动词。
- **错误信息**：用用户能理解的话说明出了什么问题，再说明该怎么做。错误代码放在详情或日志里，不放进标题。
- **隐私说明**以锁形图标开头，并且只占一行。
- 使用弯引号（“ ” ‘ ’）、真正的撇号（’）、省略号字符（…）和乘号（×），版本变化用箭头（→）：`1.2.9 → 1.3.0`。
- 产品和平台名称保持原有拼写：macOS、iPhone、App Store、GitHub、Homebrew。应用名称按开发者的写法显示。

## 中文（简体/繁體）

- 用自然、具体的口语书面语，不写套话和模板句（“一站式”“全方位”“赋能”“轻松实现”之类）。
- 按钮用动词短语：“安装”“全部更新（4）”“移到废纸篓”。不要“确定”“好的”。
- 中文与英文、数字之间加一个半角空格：“近 30 天”“下载约 768 MB”“在 OpenNavo 中打开”；与全角标点相邻时不加。
- 全角标点：，。；：？！“”（）——……；引号用“”，嵌套用‘’。
- 数量用“个”“款”“项”等合适的量词，大数用“万”“亿”（由格式化函数处理）。
- 繁体中文是独立的语言版本：用台湾、香港用户熟悉的词（“軟體”“資料夾”“設定”），不是简体的字形转换。

## 数字、容量和日期

始终通过共享的格式化函数（基于 `Intl`）来格式化，绝不用字符串拼接：

| 类型     | 规则                                                         | 示例                         |
| -------- | ------------------------------------------------------------ | ---------------------------- |
| 数量     | 按语言区域分组；空间紧张时用紧凑形式                         | 17,392 · 1.7 万 · 1,7 тыс.   |
| 容量     | 十进制单位（1 KB = 1000 B），小于 10 时保留一位小数          | 768 MB · 2.3 GB              |
| 速度     | 每秒的容量                                                   | 560.6 KB/s                   |
| 百分比   | 用整数，除非小数会改变含义                                   | 62% · 0.8%                   |
| 日期     | 按语言区域的顺序，月份用简写；当年的日期省略年份             | Oct 23 · 10月23日 · 23. Okt. |
| 相对时间 | 刚刚 → 几分钟前 → 几小时前 → 昨天 → 几天前（一周以内）→ 日期 | 2 hours ago · 昨天           |
| 时间     | 所有语言都用 24 小时制                                       | 09:00 · 21:41                |
| 时长     | 不到一分钟时只用秒，超过后用分和秒                           | 38 s · 2 min 5 s · 2 分 5 秒 |
| 版本号   | 按发布时的写法；版本之间用箭头                               | 4.49.9 → 4.50.0              |

复数使用各语言自己的复数类别（英文分 one/other；俄文分 one/few/many/other；中文和日文只有一种形式）——绝不写 `item(s)`。

## 界面语言

| 代码      | 语言               | 说明                                                |
| --------- | ------------------ | --------------------------------------------------- |
| `en-US`   | English            | 措辞的原始撰写语言；句子式大小写                    |
| `zh-CN`   | 简体中文           | OpenNavo 中语义的最终依据                           |
| `zh-Hant` | 繁體中文           | 使用台湾、香港用语；日期格式遵循 `zh-TW`            |
| `ja-JP`   | 日本語             | 礼貌、简洁；不做大写转换                            |
| `es-ES`   | Español            | 通常比英文长 25–35%                                 |
| `pt-BR`   | Português (Brasil) | 通常长 25–35%                                       |
| `ru-RU`   | Русский            | 通常长 30–60%；有四种复数形式                       |
| `de-DE`   | Deutsch            | 复合词很长；要允许换行                              |
| `fr-FR`   | Français           | 冒号、分号、问号和感叹号（: ; ? !）之前加不换行空格 |
| `it-IT`   | Italiano           | 通常长 20–30%                                       |

规则：

- **按最长的语言来设计**。13.5 px 字号下，侧边栏每项文字约有 152 px 的宽度；用俄语、西班牙语和德语对照测量，放不下就缩短译文，而不是截断。按钮可以变宽；绝不固定按钮的宽度。
- **不拼接**。使用带命名占位符（`{count}`、`{name}`）的完整句子，由译者调整占位符的位置。
- **每个语言区域都有全部的键**。缺失的翻译回退到英文，CI 会检查键和占位符。
- **品牌名和产品名**不翻译；在每种语言中，应用名都保持为 OpenNavo。
- **机器翻译**要明确标注：内容（而不是界面）由机器自动翻译时，要注明这一点，并附上原文链接。
